# Business homepage

1. Install the candidate theme and Agency Core through Dashboard → Updates. Activate Secure Custom Fields. Enable Services in **Settings → Agency Core** to feature service cards.
2. Assign the **Business Homepage** template to a Page. Save and reopen it to access the labelled fields.
3. In **Settings → Reading**, select that Page as the static homepage. Leave the existing posts page assigned if the site has one.

Set a Hero headline independently of the Page title, which supplies the fallback. The featured image supplies the hero image. Fill in the hero text and business introduction. Select published Services in the order they should appear. Each card uses the corresponding Service title, excerpt and featured image. The hero contact button uses the existing Contact button label and URL. If a Contact heading is also set, the closing section repeats that action. Explore services links to the featured services section whenever it has published cards.

The template has fixed sections. Optional sections with no content are omitted. Existing Page body content remains available as the introduction fallback. Sites using the latest-posts homepage or a different static Page template retain that layout.

On staging, set up the template and verify the static root URL, published Service selection and order, card destinations, optional sections, and the contact link. Unpublish a selected test Service and verify that its card disappears. Check the result with long copy and at narrow viewport widths. Verify the homepage edit screen as an Editor and confirm that the post editor still uses Gutenberg.
