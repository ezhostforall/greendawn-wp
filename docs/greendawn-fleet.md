# Fleet Charging template

Install the candidate **theme and Greendawn Core** together, then assign **Greendawn Fleet Charging** to the existing `/fleet-charging-solutions/` Page. Keep its slug and imported body backup. No replacement Page, charger import, permalink change or new CPT is required.

## Fixed composition and source content

The approved audience layout reuses the shared navy image-split hero, four always-visible benefits, native charger collection, lime CTA, four-step process with two photographs and related-article track. Workplace now uses the same collection renderer with its existing identifiers, fields and order preserved. No new styling dependency, animation library or page-specific JavaScript is introduced. The completed sitewide header/footer and lazy quote drawer remain in use.

Fleet keeps its existing heading/intro, benefit descriptions, charger introduction, **Aftercare & Fleet Charging** CTA and all four Fleet-specific process descriptions. It does not use Workplace’s process or the homepage/Public Charging process. The hero’s visual split reads “EV Charging For / Your Fleets”. Current source claims are retained, not newly researched manufacturer, cost or grant guarantees.

**There is no inline page-body form in the source inventory or approved Fleet design.** Do not copy Workplace’s form panel or the old site’s duplicated footer forms into this Page. Start Your Journey remains an ordinary local `/enquire/` link. The existing header/launcher and product-aware quote drawer remain available according to sitewide settings. This template adds no CF7 selector, form, mail recipient or delivery change.

SCF provides fixed Hero, Benefits, Chargers, Call to action, Process and Articles tabs. Editors can update copy/media and reorder selected records, but cannot change the design, section order, spacing or columns. Gutenberg/the classic body editor are disabled on this template only. The imported `post_content` stays stored and is never appended or executed. Password-protected Pages show the native WordPress password form before structured content is rendered.

Unset copy fields show Core-owned source defaults without writing saved metadata. Saved blanks and cleared selections stay empty. Values belong to each Page; editing Fleet does not change Workplace, About or the homepage. Native metadata still renders with SCF inactive. With Core absent, native saved values remain available and unset values degrade to the Page title/empty sections.

## Native media and relationships

The hero uses the Page’s featured image if its dedicated field is unset, otherwise the locally uploaded `2026/11/commercial-ev-fleet-charging-bays-1200.webp`. Process fields resolve local attachments for `2025/09/SA-ev.avif` and `2024/11/Electricians-at-fuse-board.png`. WordPress `-scaled` variants are supported. If these source originals are not in the Media Library, upload/select them manually; no old-domain remote fallback or replacement-image script runs. Saved cleared media is omitted, including when the Page has a featured image. Review attachment alt text. Hero media is responsive, eager and high priority; below-fold media is lazy-loaded.

The six charger defaults use existing published, password-free native records, in source order:

Cards use the record’s actual title, featured image and local detail permalink; product images are contained. Request Quote opens the detail first, then its existing quote journey carries the canonical charger identity. No product specifications or descriptions are duplicated into Page fields.

Articles select all ten existing source destinations, using the same source slug list as Workplace/About. Drag either relationship to reorder. Invalid types, unpublished/passworded records and duplicates are excluded from public rendering. Saved empty selections remove the collection. Articles retain native local permalinks and a non-autoplay track that works without JavaScript; optional controls respect reduced motion.

## Staging acceptance

1. Assign the template to the existing Page, save/reopen, then review the fixed editing tabs and prefilled Fleet copy. Confirm the imported body backup remains intact and is not duplicated in the front end.
2. Review the hero and two process photographs, including attachment health/alt text. Confirm all six chargers and ten intended articles have imported native records and the correct order.
3. Check 320px, tablet and desktop layouts: readable visible benefits, one H1, 1/2/3-column charger grid, contained product images, compact process and no horizontal page overflow. Confirm there is no additional inline form.
4. Follow the CTA and articles on the staging host. Follow a charger detail to Request Quote and verify the selected product. Recheck Workplace’s collection and existing inline form, plus About/homepage/header/footer.

Disposable CI checks cover SCF defaults before saving, saved blanks, featured/local media fallback, editor/group scope, independent process values, filtered relationships and import preservation. Browser checks cover no JavaScript/SCF, responsive screenshots, complete source copy, all destinations, empty/protected states, keyboard-accessible article controls, Axe and CTA/product journeys. CI photograph/title fixtures do not certify the actual imported product photographs; review those on staging. No live Page, form or recipient is changed by the fixtures.
