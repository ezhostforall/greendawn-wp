# About page

1. Update Greendawn and Greendawn Core on staging and activate Secure Custom Fields.
2. Create or open the About Page and assign the **About** template. Set a featured image if the header needs one.
3. Save and reopen the Page to edit its introduction, story heading, story and optional story image. Fill in the contact button label and URL to display the button.
4. Publish or update the Page and verify it at its public URL.

The template keeps the layout fixed. The story falls back to the existing Page body when the story field is empty. Optional images and the contact button are omitted when they are unavailable.

On staging, verify the populated and minimal layouts, check the Contact and About featured images at desktop and mobile widths, and check that the About contact button opens the Contact page.
